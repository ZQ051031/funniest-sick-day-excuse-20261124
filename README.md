A make.fun entry for **The Funniest Sick-Day Excuse** competition: exactly one line, one half-believable excuse for calling in sick.

## The entry

> My doctor says I've got a severe case of meeting-itis — it's contagious to calendars, and the only cure is 24 hours of bed rest and absolutely zero Zoom calls.

## Run it

```bash
python3 main.py   # writes the entry to /output/entry.txt
```

Standard library only — no third-party dependencies.
